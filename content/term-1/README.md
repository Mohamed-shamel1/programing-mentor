# Term 1 Educational Content (الفصل الدراسي الأول)

## Overview
This directory serves as the repository for verified Term 1 lesson content for Grade 11 "Programming & AI".

## Directory Policy:
1. **No Invented Content**: Content files are added only when lessons are analyzed and officially verified against the curriculum specification.
2. **Standard Format**: Each lesson will be stored as structured data conforming to `content/curriculum/lesson-schema.json`.
3. **Independent Page Composition**: Each lesson selects its own composition of educational page types (e.g. Mission, Concept, Comparison, Activity, Revision) without being forced into an inflexible rigid template.
