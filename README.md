# The Mentor — المُرشد الذكي
### منصة التعلم الذكي ونظام الكتيبات التعليمية المطبوعة
**مادة البرمجة والذكاء الاصطناعي — البكالوريا المصرية (الصف الأول الثانوي)**  
**العام الدراسي: 2026–2027**

---

## 1. نبذة عن المشروع (Project Overview)
"The Mentor — المُرشد الذكي" هو نظام تعليمي مزدوج يجمع بين:
1. **تجربة قراءة وتفاعل ويب متقدمة** للدروس البرمجية والذكاء الاصطناعي.
2. **نظام طباعة كتيبات تعليمية A4 فائق الدقة** يدمج رصانة الكتاب المدرسي، وعملية كراسة الأنشطة (Workbook)، وتوجيهات دليل المعلم.

المشروع مبني بهيكلية معمارية تفصل تماماً بين **بيانات المنهج الرسمي** و**طبقة العرض البرمجية**، مما يتيح التوليد الديناميكي لكافة دروس المنهج الـ 23 دون كتابة كود مخصص لكل درس.

## 3. المبادئ المعمارية الصارمة (Architectural Principles)
1. **RTL-First & Print-First**: واجهة تبدأ من اليمين لليسار، مع دعم حقيقي لمقاييس A4 portrait وفواصل الصفحات دون الاعتماد على هوامش المتصفح الافتراضية.
2. **لا لخلط الحقائق التعليمية بالكود**: المكونات لا تحتوي على حقائق دراسية مسبقة الصنع. المحتوى يتدفق ديناميكياً عبر وسائط المكونات (Props).
3. **لا وجود للمكونات الزجاجية (No Glassmorphism)**: الاعتماد على بطاقات ذات حدود دقيقة وظلال مضبوطة تتناسب مع الطباعة الورقية والوضوح البصري.
4. **نظام توليد الدروس (Lesson Compilation)**: كل درس يحدد تسلسل صفحاته بحرية تامة دون إجباره على قالب جامد.

## 4. تعليمات التشغيل (How to Run)

### متطلبات التشغيل:
- Node.js (v18+)
- npm (v9+)

### تشغيل خادم التطوير المحلي:
```bash
npm run dev
```

### بناء حزمة الإنتاج (Production Build):
```bash
npm run build
```

### معاينة حزمة الإنتاج:
```bash
npm run preview
```
